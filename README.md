# Lab 1

## APIs Utilizadas
1. **TheMealDB** - Comidas aleatorias
2. **CocktailDB** - Bebidas aleatorias  
3. **REST Countries** - Países aleatorios
4. **Jikan API** - Búsqueda de anime

## Archivos
- `index.html` - Página principal
- `styles.css` - Estilos básicos
- `comida.js` - API de comidas
- `bebida.js` - API de bebidas  
- `pais.js` - API de países
- `anime.js` - API de anime
- `main.js` - Funciones compartidas

## Estados
- Loading (cargando)
- Error (fallos)
- Results (resultados)
- Empty (sin resultados)
