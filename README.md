## Descripción del Proyecto
Aplicación web para practicar operaciones CRUD (GET, POST, DELETE) usando JSON Server como API simulada. El proyecto permite crear, visualizar y eliminar posts con imagen, título y descripción.

## Funcionalidades
- **GET**: Obtener y mostrar todos los posts
- **POST**: Crear nuevos posts con formulario
- **DELETE**: Eliminar posts existentes
- Validación básica de formularios
